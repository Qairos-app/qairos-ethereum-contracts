# Support

Contact: support@qairos.tech

For non-sensitive bugs, use the GitHub issue forms. Include repository, version, operating system, expected behavior and a redacted reproduction.
For vulnerabilities, follow [SECURITY.md](SECURITY.md). Never send keys or credentials.
For transaction questions, use a public transaction hash only if you are comfortable sharing it.
Do not assume a pending hash has succeeded; inspect its receipt on the correct network.
Qairos does not promise financial returns, refunds of gas, recovery guarantees or uninterrupted third-party RPC/quantum-random availability.
