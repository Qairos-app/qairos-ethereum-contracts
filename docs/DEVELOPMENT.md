# Development

Install the pinned lockfile with `pnpm install --frozen-lockfile`. Run `pnpm run validate` before changing public behavior. Follow CONTRIBUTING.md for tests, commits and review. Use unfunded ephemeral identities and a separate development database; no CI job broadcasts Mainnet transactions.

See CONFIGURATION.md and DEPLOYMENT.md for environment-specific setup. All product text and documentation are English; timestamps are UTC.
